# New Green Lawns Public School - 3D Interactive Website

An interactive **3D School Website** for **New Green Lawns Public School** (CBSE Affiliated, Estd. 1994, Sector 62, Noida). Built with pure modern web technologies (HTML5, CSS3, WebGL 3D, and Vanilla JavaScript).

## 🌟 Highlights & Features

- **Interactive 3D WebGL Hero Canvas**: Concentric golden armillary rings and celestial particle physics reacting to cursor and touch.
- **3D Interactive Virtual Campus Tour**: Axonometric 3D campus model with 360° orbit controls, zoom, pan, day/sunset/night lighting modes, and clickable facility hotspot pins.
- **Multi-Step Admission Enquiry Wizard**: Interactive modal wizard with instant validation, application reference ID generation, and prospectus download.
- **Interactive School Fee Calculator**: Live calculation for tuition, activity fees, lab fees, transport zones, cafeteria meal program, and sibling concessions.
- **Multi-Page Architecture**:
  - `Home` (`#/`) - Complete homepage matching the school design
  - `About Us` (`#/about`) - 30-year legacy timeline, Principal's address, Vision & Mission
  - `Academics` (`#/academics`) - Pre-School, Primary, Middle, and Senior Secondary (Science, Commerce, Humanities)
  - `Admissions` (`#/admissions`) - Criteria, interactive fee calculator, online admission form
  - `Campus Life` (`#/campus-life`) - 3D Virtual Campus Explorer and facility specs
  - `Achievements` (`#/achievements`) - 100% CBSE board results, Olympiad medals, alumni hall of fame
  - `Beyond Classroom` (`#/beyond-classroom`) - 18+ student clubs, excursions, and activities
  - `Contact Us` (`#/contact`) - Campus directory, address, and visit scheduler
  - `Parents Portal` (`#/parents-portal`) - Student ERP dashboard preview
  - `Mandatory Disclosures` (`#/mandatory-disclosures`) - Official CBSE compliance table
- **Spotlight Search (`Cmd/Ctrl + K`)**: Instant search across all curriculum streams, facilities, and fees.
- **3D Card Gyroscope Tilt**: Mouse-tracking perspective tilt and dynamic cursor glare reflection.
- **100% Self-Contained**: Runs directly offline in any browser without external dependencies.

## 🚀 How to Run Locally

Simply open `index.html` in your browser:
```bash
open index.html
```

Or serve with Python:
```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080` in your web browser.
